# PulseTrade

A professional trading terminal connecting to Deriv's official APIs — original UI,
demo-account-first development, no custody of user funds.

## Structure
- `frontend/` — Next.js + TypeScript + Tailwind trading terminal
- `backend/` — FastAPI + PostgreSQL + Redis + Celery
- `docker/` — local dev orchestration
- `docs/` — architecture notes, API docs
